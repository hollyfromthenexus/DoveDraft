# DoveDraft

A Godot framework for freaks and nerds.

---

## Requirements

- Godot 4.7
- YarnSpinner-Godot 0.3.12

## Install

```
# (in the root of your Godot project)
cd addons
git submodule add https://github.com/hollyfromthenexus/DoveDraft.git

cd DoveDraft
dotnet tool restore
uvx pre-commit install
```

...then open the project, build, and enable the plugin from the project settings.
